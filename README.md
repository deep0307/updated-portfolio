# Portfolio

This is my personal portfolio website — a clean, elegant software engineer portfolio built with **React + Vite** on the frontend and a **Node.js + Express** backend.

## Tech Stack

- **Frontend:** React 18, Vite, CSS (custom properties for theming), scroll-reveal animations
- **Backend:** Node.js, Express — serves content as a simple REST API
- **Skill icons:** rendered from [Simple Icons](https://simpleicons.org/) via jsDelivr, keyed by slug
